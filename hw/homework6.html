Statistical Independence

Contingency tables, expected frequencies and the chi-square test of independence

Theory · What independence means

In probability

Two events A and B are independent if P(A ∩ B) = P(A)·P(B), equivalently P(A | B) = P(A) when P(B) > 0: knowing B does not change the probability of A. Two discrete random variables X and F are independent if the same holds for every pair of values:

P(X = x, F = f) = P(X = x)·P(F = f)  for all x, f  ⇔  P(F = f | X = x) = P(F = f)  for all x, f

In words: the conditional distribution of F is the same for every value of X, and it equals the marginal distribution of F. For numerical variables, independence implies zero covariance, but the converse is false: if X is symmetric around 0 and F = X², then Cov(X, F) = 0 although F is a function of X. Independence is therefore a statement about the whole joint distribution, not only about linear correlation.

In a contingency table

A bivariate dataset (X, F) of N observations is summarised by the table of counts nij (number of observations with X = xi and F = fj), with row totals ni·, column totals n·j and grand total N. The relative frequencies play the role of probabilities:

joint  fij = nij/N
marginal  fi· = ni·/N,  f·j = n·j/N
conditional  f(F = fj | X = xi) = nij/ni·,  f(X = xi | F = fj) = nij/n·j

Perfect statistical independence in the data means fij = fi··f·j for every cell, that is, all the rows of the table of conditional frequencies are equal to the marginal distribution (the table has rank one). Multiplying by N, the expected frequencies under independence are

Eij = N·fi··f·j = ni··n·j / N

The chi-square test

Real samples are never exactly independent, so we ask whether the gap between observed and expected counts is compatible with sampling noise. The null hypothesis H0 is that X and F are independent in the population. Pearson's statistic is

χ² = Σi,j (Oij − Eij)² / Eij,  with Oij = nij
degrees of freedom: df = (r − 1)(c − 1)  (r rows, c columns)
p-value = P(χ²df ≥ χ²observed) = Q(df/2, χ²/2)  (Q = regularised upper incomplete gamma function)

Under H0 the statistic has asymptotically a χ² distribution with df degrees of freedom (rule of thumb: all Eij ≥ 5). We reject H0 at level α if p < α, equivalently if χ² exceeds the critical value. The statistic grows with N, so it measures evidence, not strength; for the strength of the association we also report Cramér's V = √(χ² / (N·min(r − 1, c − 1))), a number between 0 (independence) and 1 (each value of X determines F). For 2×2 tables the table also gives the Yates continuity-corrected statistic.

The standardized residuals (O − E)/√E show which cells drive the result: values beyond ±2 are unusually large (positive: more observations than independence predicts; negative: fewer).

4 · Interpretation

Association is not causation · the Berkeley admissions data

The pooled Berkeley table (dataset above) shows a clear association between gender and admission: men were admitted more often than women. Does it mean that the admission procedure discriminated against women? The data were also recorded by department, and the same test run inside each department gives a different picture (Simpson's paradox):

Department is a confounder: it is related to gender (women applied in larger proportion to departments with low admission rates, C to F) and to admission (the admission rate depends strongly on the department). The pooled association is real as a description of the data, but the effect of gender on the decision must be measured within each department.

Code · the same computation in Python

Pure Python for the table and the statistic; scipy.stats.chi2.sf only for the optional p-value. The page above runs the same formulas in JavaScript (the p-value uses the incomplete gamma function). 

from collections import Counter
from scipy.stats import chi2          # only for the optional p-value

def contingency(pairs, xs=None, fs=None):
    """pairs: list of (x, f) observations -> categories and table of counts."""
    xs = xs or sorted({x for x, _ in pairs})
    fs = fs or sorted({f for _, f in pairs})
    cnt = Counter(pairs)
    return xs, fs, [[cnt[(x, f)] for f in fs] for x in xs]

def analyze(pairs, xs=None, fs=None):
    xs, fs, O = contingency(pairs, xs, fs)
    r, c, N = len(xs), len(fs), len(pairs)
    R = [sum(row) for row in O]                                  # row totals n_i.
    C = [sum(O[i][j] for i in range(r)) for j in range(c)]       # column totals n_.j
    joint = [[O[i][j] / N for j in range(c)] for i in range(r)]  # f_ij
    f_x = [R[i] / N for i in range(r)]                           # marginal f_i.
    f_f = [C[j] / N for j in range(c)]                           # marginal f_.j
    cond_f_given_x = [[O[i][j] / R[i] for j in range(c)] for i in range(r)]
    cond_x_given_f = [[O[i][j] / C[j] for j in range(c)] for i in range(r)]
    E = [[R[i] * C[j] / N for j in range(c)] for i in range(r)]  # expected under independence
    stat = sum((O[i][j] - E[i][j]) ** 2 / E[i][j] for i in range(r) for j in range(c))
    df = (r - 1) * (c - 1)
    p = chi2.sf(stat, df)                                        # P(chi2_df >= stat)
    V = (stat / (N * min(r - 1, c - 1))) ** 0.5                  # Cramer's V
    return dict(xs=xs, fs=fs, O=O, E=E, stat=stat, df=df, p=p, V=V,
                f_x=f_x, f_f=f_f, cond_f_given_x=cond_f_given_x, cond_x_given_f=cond_x_given_f)

Conclusions

Titanic (class × survival). The observed counts are far from the counts expected under independence: χ² = 190.4 with 3 degrees of freedom, p ≈ 5·10−41, Cramér's V ≈ 0.29. We reject independence: survival depends on the class of travel. The conditional frequencies show how: 62.5% of the first-class passengers survived, against 41.4% in second class, 25.2% in third class and 24.0% among the crew. All expected counts are far above 5, so the χ² approximation is reliable.

Simulated data. Two variables generated independently give small statistics and large p-values (try different seeds: at α = 0.05 about one dataset in twenty is rejected by chance, a false positive), while a dataset generated with a dependence is rejected as soon as N is large enough. A p-value above α does not prove independence: it only says that the data are compatible with it, and with small N the test has little power.

Association is not causation. The χ² test measures statistical association between two variables, and a small p-value says that the association is unlikely to be a sampling accident. It does not say why the variables are related. Three explanations are always possible: X influences F, F influences X, or a third variable influences both (a confounder). In the Berkeley data the pooled association between gender and admission (χ² = 92.2, df = 1, p ≈ 8·10−22, V ≈ 0.14) almost disappears inside the departments, where five of the six tables show no significant association, and department A even shows a significant difference in favour of women. Causal conclusions need a study design that controls the confounders (randomisation) or an explicit causal model, not a test of independence.
