Correlation and Regression

Least-squares lines, the link r² = b·b′, and why independence implies uncorrelation

1 · Correlation, regression, and how they are related

For a dataset of pairs (xi, yi), i = 1, …, n, write x̄ and ȳ for the means and

Sxx = Σ (xi − x̄)²,  Syy = Σ (yi − ȳ)²,  Sxy = Σ (xi − x̄)(yi − ȳ)
covariance: sxy = Sxy/(n − 1)    standard deviations: sx = √(Sxx/(n − 1)), sy = √(Syy/(n − 1))
Pearson correlation: r = Sxy / √(Sxx Syy) = sxy / (sx sy)

The covariance has the units of x times the units of y and its size depends on the scale. The correlation r divides by the two standard deviations: it is dimensionless and always in [−1, 1] (Cauchy–Schwarz: Sxy² ≤ Sxx Syy). It measures linear association: r = ±1 exactly when all points lie on a line, and r = 0 means no linear trend, not no relationship. A correlation says nothing about causation.

The regression problem: finding a and b

Regression of y on x looks for the line ŷ = a + b x that minimises the sum of squared vertical errors

S(a, b) = Σ (yi − a − b xi)²

Set the two partial derivatives to zero (the normal equations):

∂S/∂a = −2 Σ (yi − a − b xi) = 0  ⇒  a = ȳ − b x̄   (the line passes through the point of means)
∂S/∂b = −2 Σ xi (yi − a − b xi) = 0  ⇒  substituting a:  b Σ (xi − x̄)² = Σ (xi − x̄)(yi − ȳ)
b = Sxy / Sxx = r · sy/sx,  a = ȳ − b x̄

The critical point is a minimum: the Hessian of S is 2·[[n, Σx], [Σx, Σx²]], whose determinant is 4n·Sxx > 0 when the xi are not all equal. The slope has the sign of r, and the residuals ei = yi − a − b xi satisfy Σ ei = 0 and Σ xi ei = 0 (the normal equations themselves).

Exchanging the roles of the variables gives the regression of x on y, x̂ = a′ + b′ y, with

b′ = Sxy / Syy = r · sx/sy,  a′ = x̄ − b′ ȳ

These are two different lines (the first minimises vertical errors, the second horizontal ones). They always cross at (x̄, ȳ). Multiplying the two slopes:

b · b′ = (Sxy/Sxx) · (Sxy/Syy) = Sxy² / (Sxx Syy) = r²
⇒  r = ± √(b · b′),  with the sign common to b and b′ (the sign of Sxy)

So |r| is the geometric mean of the two regression coefficients. Two consequences: b and b′ always have the same sign, and since |r| ≤ 1 we get |b·b′| ≤ 1; the two lines coincide only if |r| = 1, and they get further apart as r approaches 0 (for r = 0 they are the horizontal line y = ȳ and the vertical line x = x̄). The coefficient of determination r² = b·b′ is also the fraction of the variance of y explained by the line: Σ (yi − ȳ)² = Σ (ŷi − ȳ)² + Σ ei², with Σ (ŷi − ȳ)² = r² Syy.

Independence implies uncorrelation

Claim. If X and Y are independent random variables with finite variances, then Cov(X, Y) = 0 and hence ρ(X, Y) = 0.

Proof. Independence means that the joint law factorises, f(x, y) = fX(x) fY(y) (sums instead of integrals in the discrete case). Then

E[XY] = ∬ x y fX(x) fY(y) dx dy = ( ∫ x fX(x) dx ) ( ∫ y fY(y) dy ) = E[X] E[Y]
Cov(X, Y) = E[XY] − E[X] E[Y] = 0  ⇒  ρ = Cov(X, Y)/(σX σY) = 0  (when σX, σY > 0)  ∎

The converse is false. Let X be symmetric around 0 (for example X ~ N(0, 1)) and Y = X². Then E[X] = 0 and E[XY] = E[X³] = 0 (odd moment of a symmetric law), so Cov(X, Y) = E[XY] − E[X]E[Y] = 0: uncorrelated. But Y is a function of X, hence completely dependent: P(Y > 1 | X > 1) = 1 while P(Y > 1) = P(|X| > 1) ≈ 0.317. Uncorrelation is only the absence of a linear trend; independence is the absence of any relationship. The two are equivalent in the special case of a jointly Gaussian pair (X, Y). The check: r from the two regression coefficients
Why (a, b) is the minimum: squared error of the fitted line against perturbed lines
Python code for the same computation
import numpy as np

def regress(x, y):
    x, y = np.asarray(x, float), np.asarray(y, float)
    dx, dy = x - x.mean(), y - y.mean()
    sxx, syy, sxy = dx @ dx, dy @ dy, dx @ dy
    b  = sxy / sxx;  a  = y.mean() - b  * x.mean()     # y on x
    b2 = sxy / syy;  a2 = x.mean() - b2 * y.mean()     # x on y
    r  = sxy / np.sqrt(sxx * syy)
    return a, b, a2, b2, r

a, b, a2, b2, r = regress(x, y)
print(r, np.sign(b) * np.sqrt(b * b2))                  # equal
print(np.corrcoef(x, y)[0, 1])                          # numpy agrees

4 · Conclusions
  • The least-squares line of y on x is ŷ = a + b x with b = Sxy/Sxx = r sy/sx and a = ȳ − b x̄; the line of x on y has slope b′ = Sxy/Syy. They are different lines through (x̄, ȳ).
  • b · b′ = r², so |r| = √(b · b′), the geometric mean of the two coefficients, with the sign of the covariance. The experiment confirms it to machine precision on every dataset.
  • The Anscombe datasets have (almost) the same r, means and lines but very different shapes: r and the regression line must always be read together with the scatter plot.
  • Independence ⇒ Cov = 0 by factorisation of the expectation, but uncorrelated variables can be strongly dependent (Y = X²); only the Gaussian case gives the equivalence.
