Riemann vs Lebesgue Integration, and the Normal CDF

Two ways of building an integral, and how to compute Φ(x) numerically

Exercise 1 · Riemann and Lebesgue integration

The two constructions

Riemann. Partition the domain [a, b] into n subintervals of width Δx = (b − a)/n and add up (value of f at a tag point) × (width):

Rn = Σi=0..n−1 f(ξi)·Δx   (left tags ξi = a + iΔx; midpoint tags ξi = a + (i + ½)Δx)

Lebesgue. Partition the range into K levels yj = ymin + j·h, and weight each level with the measure of the preimage Ej = {x : yj ≤ f(x) < yj+1}:

LK = Σj=0..K−1 yj·μ(Ej)   (integral of a simple function below f; the last level is closed at the top)

Writing d(y) = μ{x : f(x) ≥ y} for the distribution function, μ(Ej) = d(yj) − d(yj+1), and summing by parts LK becomes ymin·d(ymin) + h·Σ d(yj): a Riemann sum for ∫ d(t) dt, the “layer-cake” formula. So Lebesgue's method is Riemann's method applied to the other axis.

Three numerical versions are compared, all with the same number n of pieces (n = K):

  • Riemann left / Riemann midpoint: partition of the domain, n evaluations of f.
  • Lebesgue, exact preimages: partition of the range, with μ(Ej) computed from the distribution function d(y) (closed forms, or bisection for sin(x)/x). It needs the preimage of f to be computable.
  • Lebesgue, sampled preimages: what one can do for a black-box f: evaluate f at n midpoints, sort the values into K range bins and estimate μ(Ej) by the fraction of points in each bin.

Conventions: for 1/√x (unbounded) the range is cut at M = √K with step h = 1/√K (this balances the truncation error 1/M and the discretization error h); the left sum uses f(0) := 0; sin(x)/x uses f(0) = 1. The values of n are odd (11, 101, …), so that no left tag falls exactly on the jump at 0.5.

Pathological functions

The Dirichlet function

f(x) = 1 if x is rational, 0 if x is irrational. Every subinterval of every partition contains both rational and irrational numbers, so the upper Darboux sum is always 1 and the lower sum is always 0: f is not Riemann-integrable, and the value of a Riemann sum is decided by the choice of the tags. In the Lebesgue construction the range has two levels, and the preimage of 1 is ℚ ∩ [0, 1]. This set is countable, hence has measure 0 (cover the k-th rational with an interval of length ε/2k: the total length is ≤ ε for every ε). Therefore ∫ f dμ = 1·0 + 0·1 = 0.

Numerically the function cannot even be sampled: every floating-point number is a rational number (a ratio of an integer and a power of 2), so a program that tests “is x rational?” on a computer value can only answer yes. The Lebesgue result is a statement about measure, not something that a finite grid can discover.

Thomae's function

f(p/q) = 1/q for p/q in lowest terms, f(x) = 0 for x irrational. It is discontinuous at every rational and continuous at every irrational point. Its set of discontinuities (ℚ) has measure zero, so by Lebesgue's criterion f is Riemann-integrable. The table computes the upper Darboux sum Un exactly on the partition into n equal intervals: the supremum on [i/n, (i + 1)/n] is 1/qmin, where qmin is the smallest denominator of a rational in the interval. The lower sum is always 0 (irrational numbers are everywhere).

Un → 0, so the Riemann integral exists and is 0. The Lebesgue integral is also 0: for every t > 0 the set {f ≥ t} is finite (only denominators q ≤ 1/t), so it has measure 0 and the layer-cake integral ∫ μ{f ≥ t} dt vanishes. Here the two theories agree, but Riemann needs a limit of partitions to see it, while Lebesgue sees it at once.

Conclusions of Exercise 1

Agreement. For every Riemann-integrable function above, the two constructions converge to the same number (the table shows the errors going to 0 for all of them). This is a theorem: a Riemann-integrable function is Lebesgue-integrable with the same integral. The converse fails (Dirichlet), so the Lebesgue integral is a strict extension.

Accuracy and convergence. With n pieces the Riemann left sum has error O(1/n) for smooth functions and the midpoint rule O(1/n²): both exploit the smoothness of f along the domain. The Lebesgue sum with exact preimages has error at most h·(length of the domain) = O(1/K) for every bounded function, smooth or not: its accuracy is tied to the range step, and it does not improve with smoothness. This is why it is the best method for step functions (the jump functions are integrated with error about 1/K, set by the level step; with only two values, the levels {1, 3} describe them exactly). The sampled version has the cost of Riemann and an accuracy that depends on the bins and on the sample: it works for any black-box f, but it is not better than the midpoint rule. For the unbounded 1/√x all methods converge slowly, like n−1/2, because of the singularity at 0.

Efficiency. A Riemann sum needs only n evaluations of f, in any dimension and for any f. The Lebesgue sum needs the measure of a preimage, which requires inverting f (closed form, or a root finder as for sin(x)/x, about 60 evaluations of f per level) or sorting samples; in return it can handle discontinuous and wildly oscillating functions, and it is the idea that generalizes to probability: E[X] = ∫ x dP is exactly a Lebesgue integral over the values of X, and Monte Carlo sampling is the “sampled preimage” method.

Exercise 2 · Numerical computation of the normal CDF

Definition

Φ(x) = ∫−∞x φ(t) dt,  φ(t) = e−t²/2/√(2π)
Φ(x) = ½·(1 + erf(x/√2)),  erf(z) = (2/√π) ∫0z e−s² ds
Φ(−x) = 1 − Φ(x)   (symmetry),  Φ(0) = ½

Why Φ is not an elementary function (Liouville)

A function is elementary if it can be built from the rational functions, exp and log (and algebraic functions) by finitely many sums, products, compositions and inverses. Liouville's theorem on elementary integration (1833–35; the algorithmic version is the Risch algorithm) says, in the case that we need:

Let f, g be rational functions, g not constant. Then ∫ f(x)·eg(x) dx is elementary if and only if there is a rational function R with  R′ + g′·R = f,  and then the integral is R·eg.

For Φ we need f = 1 and g = −x²/2 (so g′ = −x), that is, a rational R with R′ − x·R = 1. There is none:

  • If R had a pole of order k ≥ 1 at some point c, then R′ would have a pole of order k + 1 there, while x·R has a pole of order at most k. The difference R′ − xR would still have a pole at c, so it cannot be the constant 1. Hence R has no poles: it is a polynomial.
  • If R is a polynomial of degree d ≥ 0, then x·R has degree d + 1, larger than the degree d − 1 of R′, so R′ − xR has degree d + 1 ≥ 1 and cannot be the constant 1. If R = 0, then R′ − xR = 0 ≠ 1.

So ∫ e−x²/2 dx is not elementary, and neither is Φ (nor erf). This does not mean that Φ has no exact description: it only means that its description needs a new function.

Special functions and why we still need numerics

Giving the integral a name, erf, makes the relation Φ(x) = ½(1 + erf(x/√2)) exact, and the analytic properties of erf are well known (odd, entire, erf(∞) = 1, erf′(z) = (2/√π)e−z², Taylor series, asymptotic series, continued fractions). But a name is not a number: to know that Φ(1.5) = 0.9331927987… some algorithm must still compute it, from the integral, from a series, or from a rational approximation. The analytic representation moves the problem into the evaluation of erf; libraries (C erf, SciPy, R pnorm) do exactly this with carefully designed piecewise approximations. The methods implemented below follow the three suggestions of the assignment, plus a hybrid that reaches double precision:

  1. Numerical integration. Φ(x) = ½ + ∫0x φ with the trapezoidal rule (error O(N−2)) or Simpson's rule (error O(N−4)), N subintervals.
  2. Series, alternating. erf(z) = (2/√π) Σk (−1)k z2k+1/(k!(2k+1)). Converges for every z, but for large |z| the terms grow to size ez² before decreasing, and the cancellation destroys the digits.
  3. Series, positive. erf(z) = (2/√π) e−z² Σk 2k z2k+1/(1·3·5⋯(2k+1)). Same function, all terms positive: no cancellation. Needs about z² + 40 terms.
  4. erf approximation. Abramowitz–Stegun 7.1.26: erf(z) ≈ 1 − (a₁t + a₂t² + … + a₅t⁵)e−z², t = 1/(1 + 0.3275911 z), max error 1.5·10−7, only a few operations.
  5. Hybrid (series + continued fraction). For |x| < 3 use the positive series. For |x| ≥ 3 compute the tail directly with the continued fraction for the Mills ratio, Q(x) = 1 − Φ(x) = φ(x)/(x + 1/(x + 2/(x + 3/(x + …)))), and use symmetry. Computing 1 − Φ(x) as a subtraction would lose all the digits of the tail (Q(6) ≈ 10−9 is below 10−16 relative to 1).

Conclusions of Exercise 2

Accuracy. Simpson's rule beats the trapezoid rule at equal N, as its error falls like N−4 instead of N−2 (the plots show slopes −4 and −2). At large |x| the constant of the trapezoid rule is very small: its error is about (h²/12)(φ′(x) − φ′(0)) (Euler–Maclaurin), and φ′(0) = 0 while φ′ is almost zero at a far endpoint. The positive series and the hybrid reach about 15–16 digits. The alternating series is as good for small |x| but needs many more terms as |x| grows, and cannot go below about 10−16·ex²/2 because of cancellation (10−13 at x = 5, 7·10−11 at x = 6). A&S 7.1.26 gives about 7 digits with a handful of operations.

Tails. The values of Φ(−4), Φ(−5), Φ(−6) are tiny (10−5 to 10−9). Methods that go through ½(1 + erf) or ½ + ∫ have a good absolute error but lose relative accuracy there. For risk and p-value calculations the relative accuracy of the tail is what matters, which is why the hybrid evaluates the tail directly (continued fraction) instead of subtracting from 1.

Efficiency. Integration costs N evaluations of exp per point; the series cost about z² + 40; the continued fraction about 200 divisions; A&S one exp and a polynomial. In practice a library chooses between a small number of rational approximations over a few ranges of x, which is the same idea as the hybrid, tuned for speed. Exactness of a formula (Φ = ½(1 + erf)) and efficiency of a number are two different things.
